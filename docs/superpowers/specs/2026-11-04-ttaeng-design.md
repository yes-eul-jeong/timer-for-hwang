## 1. 목적

황승하 선수(프로 킥복싱)가 체육관 체력훈련과 시합장 웜업에 쓰는 인터벌 타이머. 지금 쓰는 "타이머 플러스" 앱의 사용 흐름은 좋지만 무료 사용 제한과 구독 결제가 불편하다. 광고·결제 없는 무료 웹앱으로 대체한다.

### 사용 상황 [결정]

- 휴대폰은 체육관 **바닥에 두고** 서서 내려다본다.
- 훈련 중에는 지쳐서 화면을 읽으려고 신경 쓸 여유가 없다. 한눈에 알아봐야 한다.
- 주로 쓰는 패턴

| 용도 | 운동 | 휴식 | 반복 |
|---|---|---|---|
| 인터벌 | 20초 / 30초 | 10초 / 30초 | 세트 수는 그날그날 다름 |
| 러닝머신 체력 | 20초 | 10초 | 8세트 × 3라운드 |
| 킥복싱 경기 형식 | 3분 | 1분 | 3라운드 |

### 목표

1. 1~2m 떨어진 바닥에서 지금 단계와 남은 시간을 바로 알아본다.
2. 카운트다운 소리가 정확한 박자에 나온다.
3. 저장한 타이머를 골라 오늘 세트 수만 바꾸고 바로 시작한다.
4. 앱 설치, 결제, 계정 없이 쓴다.

### 비목표 (첫 버전에서 하지 않음)

- 운동 기록 [결정]
- 메트로놈 틱 소리 [제안]
- Apple Watch, HealthKit (웹앱으로 불가능)
- 기기 간 자동 동기화, 서버, 로그인
- 타이머 순서 바꾸기, 폴더, 공유

### 실패로 보는 경우 (기능이 돌아가도 실패)

- 카운트다운 소리가 화면 숫자보다 늦거나 박자가 흔들린다. **지연은 절대 안 된다** [결정]
- 일시정지하려고 멈춤 버튼을 눌렀는데 다른 버튼이 눌린다.
- 숫자나 단계 표시를 보려고 휴대폰에 다가가야 한다.

## 3. 화면

프로토타입이 기준이다. 화면은 5개.

```
[타이머 목록] ──누름──▶ [시작 전] ──시작──▶ [운동 중]
     │                    │  ▲                  │
     │ 하단 메뉴          │  └──종료/끝──────────┘
     ├─ 추가 ──▶ [편집]◀──┘ 편집
     └─ 설정 ──▶ [설정]
```

### 3.1 하단 메뉴

- 타이머 / 추가 / 설정 3칸. 추가 칸은 액센트 색으로 칠한다. 현재 화면 칸은 위쪽에 액센트 막대를 표시한다.
- **타이머 목록과 설정 화면에만 표시한다.** 시작 전·운동 중·편집 화면에는 없다 [제안]. 운동 중 버튼을 누를 때 메뉴가 같이 눌리는 것을 막는다.

### 3.2 타이머 목록

- 카드 한 장에 이름, 요약("운동 20 · 휴식 10 · 8세트 × 3라운드"), 총 시간(m:ss)을 보여준다.
- 카드를 누르면 시작 전 화면으로 간다.
- 처음 설치하면 예시 타이머 4개가 들어 있다 [제안]: 타바타(10/20/10, 8세트), 러닝머신 체력(8세트 × 3라운드), 30/30 인터벌(10세트), 킥복싱 3분 3R(운동 180, 휴식 60, 3세트).
- 정렬은 추가한 순서.

### 3.3 시작 전

- 이름, 요약, 총 시간(크게)
- 세트와 라운드를 +/− 버튼으로 바꾼다. **여기서 바꾼 값은 저장하지 않는다** [제안]. 저장된 값을 바꾸려면 편집으로 간다.
- 화면 아래 큰 "시작" 버튼. 위쪽에 "‹ 목록", "편집"

### 3.4 편집 (추가와 같은 화면)

- 이름(최대 20자, 비우면 "20/10 인터벌" 식으로 자동 이름)
- 준비, 운동, 휴식, 세트, 라운드, 라운드 간 휴식을 +/− 스테퍼로 입력
- 시간 단위: 60초 미만은 5초, 60초 이상은 15초씩 [제안]
- 범위: 준비·휴식·라운드 간 휴식 0~3600초, 운동 5~3600초, 세트·라운드 1~99
- 기존 타이머 편집 시 "이 타이머 삭제" 버튼. 한 번 더 눌러야 삭제된다(브라우저 확인창 대신).

### 3.5 설정

- 카운트다운 소리: 삐-삐-삐(기본) / 한국어 음성 / 끔
- 소리 크기: 1~5(기본 5). 카운트다운 소리 바로 아래. 누르면 저장하고 그 크기로 "3초 전" 소리(count3)를 한 번 들려준다. 소리가 끔이면 버튼을 비활성으로 두고 "소리를 끄면 쓸 수 없어요"를 보여준다.
- 단계 바뀔 때 화면 번쩍임: 켬(기본) / 끔
- 백업 내보내기 / 불러오기, 마지막 백업 날짜 표시
- 앱 버전, "데이터는 이 휴대폰에만 저장됩니다"

### 3.6 운동 중

전면 단색 레이아웃(시안 1) [결정].

```
┌─────────────────────────┐
│ WORK           [Ⅱ 멈춤] │  단계 이름(영문 라벨 + 한글)  멈춤 버튼
│ 운동                    │
│                         │
│          20             │  현재 단계 남은 시간. 화면 대부분
│                         │
│ 세트      라운드   전체 │  남은 세트 / 남은 라운드 / 전체 남은 시간
│ 6 / 8     3 / 3    5:40 │  세트·라운드는 지금 하는 세트를 포함해서 센다
├─────────────────────────┤
│ NEXT 휴식            10 │  다음 단계 띠. 그 단계의 배경색
└─────────────────────────┘
```

- **단계 표시는 밝기로 구분한다** [결정]: 운동 = 초록 전면 + 검정 글씨, 휴식 = 검정 + 흰 글씨, 준비 = 회색 면 + 초록 숫자. 라운드 간 휴식은 휴식과 같은 색, 이름만 "라운드 휴식".
- 60초 이상은 `3:00`, 미만은 `20`으로 표시하고, 긴 형식은 숫자 크기를 줄인다. 큰 숫자 크기는 `min(86cqw, 42cqh) × 1.25`(긴 형식 `min(54cqw, 26cqh) × 1.25`, 10분 이상 `min(43cqw, 21cqh) × 1.25`).
- 아래 NEXT 띠 높이는 화면의 12%.
- 단계가 바뀌는 순간 화면 전체가 0.3초 액센트 색으로 번쩍인다(설정에서 끔 가능).
- 끝나면 "땡"을 TtaengKr 62cqw로 크게 보여주고 길게 울린다. 멈춤 버튼과 NEXT 띠는 사라지고, 그 자리(아래 띠)가 "돌아가기" 버튼이 된다. 누르면 시작 전 화면으로 간다. 화면의 다른 곳을 눌러도 아무 일도 없다.
- 세로 고정 [제안]. 가로 화면은 지원하지 않는다.

**일시정지** [결정]

- 위 오른쪽 [멈춤] 버튼으로만 일시정지한다. 화면을 눌러도 아무 일도 하지 않는다.
- 일시정지 화면은 "PAUSED"만 크게, 설명 문구 없음. 배경을 눌러도 그대로다.
- 버튼 4개(계속 / 다음 단계로 / 처음부터 / 종료)는 화면 너비 86%, 높이 화면의 11% 이상. "계속"은 액센트 색, 높이 14%로 가장 크다.
- 종료하면 시작 전 화면으로 간다.

## 5. 타이머 규칙

### 5.1 데이터

```ts
type Timer = {
  id: string;          // crypto.randomUUID()
  name: string;
  prepare: number;     // 초
  work: number;
  rest: number;        // 세트 사이 휴식
  sets: number;        // 라운드마다 반복
  rounds: number;
  roundRest: number;   // 0이면 세트 휴식(rest)을 그대로 쓴다
  createdAt: string;   // ISO
};
```

### 5.2 진행 순서

```
준비(prepare > 0일 때만)
라운드 1: 운동 → 휴식 → 운동 → … → 운동
          (라운드 마지막 세트 뒤: roundRest > 0 이면 라운드 휴식, 아니면 rest)
라운드 2: …
마지막 라운드 마지막 운동 뒤에는 휴식 없이 끝
rest 가 0이면 휴식 단계를 건너뛴다
```

- 남은 세트·라운드는 지금 하는 운동 세트를 포함해서 센다. 준비·휴식 중에는 다음에 할 운동 세트 기준으로 센다.
- 총 시간은 위 순서의 합.

### 5.3 시간 계산

- 시작 시각을 기준으로 경과 시간을 매번 계산한다. 1초마다 1씩 빼는 방식은 쓰지 않는다. 화면이 꺼졌다 돌아오거나 앱을 전환했다 돌아와도 표시가 맞다.
- 일시정지한 시간은 경과 시간에서 뺀다.
- 운동 중에는 Screen Wake Lock으로 화면을 켜둔다. 앱을 다시 볼 때(`visibilitychange`) Wake Lock을 다시 요청한다.
- 앱이 백그라운드에 있는 동안에는 소리가 나지 않을 수 있다(웹 플랫폼 제약). 돌아오면 남은 소리를 다시 예약한다.

## 6. 소리

### 6.1 지연 없는 재생 [결정]

- Web Audio API 하나로 모든 소리를 낸다. `<audio>` 태그와 Web Speech API(음성 합성)는 쓰지 않는다.
- 시작 버튼을 누르는 순간 `AudioContext`를 만들고 재개한다(iOS는 사용자 동작 없이 소리를 막는다).
- 소리는 그때그때 틀지 않고 **오디오 시계 기준 정확한 시각에 미리 예약**한다(`source.start(when)`). 일시정지하면 예약을 모두 취소하고, 재개·건너뛰기·처음부터·화면 복귀 때 다시 예약한다.
- 음성 파일은 앱 시작 시 미리 `AudioBuffer`로 디코딩해 둔다. 파일 앞뒤 무음은 잘라낸다.
- 화면 시계(`performance.now`) 기준 목표 시각을 오디오 시각으로 바꿔 예약한다. `getOutputTimestamp()`가 있으면 그것으로, 없으면 `currentTime`에서 `baseLatency + outputLatency`를 빼서 출력 지연을 보정한다.
- `AudioContext`가 running이 되기 전에는 예약하지 않고, running이 되는 순간 그때까지 흐른 시간을 반영해 예약한다.
- 신호음은 숫자가 바뀌는 순간에 울린다. 음성은 모음이 박자로 들리므로 0.05초 먼저 시작한다.
- 0.02초 넘게 지난 소리는 늦게 틀지 않고 건너뛴다.

### 6.2 신호음 (기본)

- 단계 끝나기 3, 2, 1초 전: 짧은 삐(880Hz, 0.12초)
- 단계 전환 순간: 높고 긴 삐(1320Hz, 0.45초)
- 전체 끝: 같은 높이로 0.9초
- 소리 크기 단계별 최고 음량 [0.22, 0.294, 0.392, 0.524, 0.70]. 기본 5단계.
- 파일 없이 코드로 생성(OscillatorNode)

### 6.3 한국어 음성 [결정]

- "삼", "이", "일", "시작", "휴식", "끝" 6개 파일
- macOS `say` 명령의 한국어 음성으로 생성하고 `afconvert`로 변환한다. 생성 스크립트를 레포에 둔다. 목소리는 Yuna를 기본으로 하고, 샘플을 만들어 사용자가 고른다 [제안].
- macOS 음성은 개인적·비상업적 용도로만 쓸 수 있다. 유료화하면 다른 TTS로 다시 만들어야 한다.
- 3, 2, 1초 전에 "삼", "이", "일", 전환 순간 다음 단계 이름("시작" = 운동 시작, "휴식"), 전체 끝에 "끝"
- 길이 3초 이하 단계의 카운트는 음성 모드여도 신호음으로 낸다 [결정]. 카운트 k는 단계 길이가 k보다 길 때만 낸다(단계 시작 순간의 전환음과 겹치지 않게)
- 불러올 때 파일마다 최고점(peak, 모든 채널 절댓값 최대)을 재고, GainNode로 소리 크기 단계별 목표 peak [0.45, 0.542, 0.654, 0.788, 0.95]에 맞춘다. peak가 0이면 gain 1.

### 6.4 iPhone 무음 스위치

- 무음 모드에서 웹 소리가 꺼질 수 있다. 지원되는 Safari에서는 `navigator.audioSession.type = 'playback'`을 설정한다.
- 실제 iPhone에서 동작을 확인한다(8장). 안 되면 시작 화면에 "무음 모드를 끄세요" 안내를 넣는다.

## 7. 저장과 백업

- 타이머 목록: IndexedDB. 설정값: localStorage
- 첫 실행 때 `navigator.storage.persist()` 요청
- 백업 파일 `timer-backup-YYYY-MM-DD.json`. 운동 기록이 빠졌으므로 `history`는 없다.

```json
{
  "app": "ttaeng",
  "version": 1,
  "exportedAt": "2026-11-04T09:00:00Z",
  "timers": [
    { "id": "…", "name": "러닝머신 체력", "prepare": 10, "work": 20, "rest": 10, "sets": 8, "rounds": 3, "roundRest": 0, "createdAt": "…" }
```

- `volume`이 없거나 1~5 정수가 아니면 5로 읽는다(그 필드만). `sound`·`flash`가 깨지면 설정 전체를 기본값으로 한다.
- 내보내기: iPhone은 `navigator.share`(파일 공유 시트), 지원하지 않으면 다운로드
- 불러오기: 파일 선택 → `app`, `version`, 각 필드 검사 → 덮어쓰기 / 합치기 선택. 합치기는 `id`가 같으면 불러온 쪽으로 바꾼다.
- 마지막 백업 후 30일이 지나면 설정 화면에 백업 권유 문구를 띄운다 [제안].

## 8. 기술

- Vite + TypeScript + **Vue 3** [결정]
- PWA: Web App Manifest(`display: standalone`, `orientation: portrait`, 배경색 `#0A0A0A`), Service Worker로 전체 오프라인 캐시. `vite-plugin-pwa` 사용 [제안]
- GitHub Pages 경로 `/timer-for-hwang/`에 맞춰 `base` 설정, GitHub Actions로 배포
- iPhone 홈 화면 추가 안내: Safari에서 처음 열고 아직 설치하지 않았으면 "공유 → 홈 화면에 추가" 안내를 한 번 보여준다
- Docker: 소개 페이지 레포와 같은 방식(`docker/Dockerfile`, `docker/compose.yml`, `node:22-bookworm-slim`). node_modules 는 리눅스 바이너리가 섞이지 않게 named volume 에 둔다. 개발 서버는 컨테이너 5173, 호스트 5180(호스트 5173은 다른 프로젝트가 사용 중)

### 테스트

- 단위 테스트(Vitest): 진행 순서 생성, 남은 세트·라운드 계산, 경과 시간 → 상태 변환, 백업 검사·합치기
- 실제 기기 확인 목록(iPhone 필수, Android 1대)
  1. 카운트다운 소리와 숫자 변경이 맞는지(화면 녹화 + 소리로 확인)
  2. 무음 스위치 켠 상태에서 소리
  3. Wake Lock으로 화면이 안 꺼지는지
  4. 화면을 껐다 켜거나 앱을 전환한 뒤 남은 시간이 맞는지
  5. 홈 화면 설치 후 비행기 모드에서 실행
  6. 백업 내보내기 → 앱 삭제 → 재설치 → 불러오기
