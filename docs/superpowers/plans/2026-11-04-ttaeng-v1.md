> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 확정 설계대로 타이머 목록·편집·설정·시작 전·운동 중 화면과 지연 없는 소리, 로컬 저장, 백업을 갖춘 PWA 첫 버전을 만든다.

**Architecture:** 화면과 무관한 순수 로직(`src/core`, `src/audio/cues.ts`, `src/storage/backup.ts`)을 먼저 테스트와 함께 만들고, 그 위에 Vue 컴포넌트를 얹는다. 라우터 없이 전역 스토어의 `view` 값으로 화면을 바꾼다. 시간은 "시작 시각 기준 경과 시간"에서 매 프레임 상태를 계산하고, 소리는 Web Audio 시계에 미리 예약한다.

**Tech Stack:** Vue 3.5 (`<script setup>`), Vite 8, TypeScript 6, Vitest 5 + jsdom + @vue/test-utils, Sass, vite-plugin-pwa 2, fake-indexeddb(테스트), @fontsource/barlow-condensed·pretendard(npm 글꼴)

**Spec:** `docs/superpowers/specs/2026-11-04-ttaeng-design.md` (화면 기준은 프로토타입 https://claude.ai/artifact/EzdtfWv3x5sZgiaNVg2i1s)

## Global Constraints

- 모든 Node 명령은 컨테이너에서 실행한다. 이 문서의 `$DC`는 `docker compose -f docker/compose.yml run --rm app` 이다. 호스트에서 `node`/`npm`/`npx` 금지.
- 색·글꼴·간격은 `src/styles/_tokens.scss`의 CSS 변수(`--c-*`, `--font-num`/`--font-kr`, `--s-*`)만 쓴다. 값 직접 기입 금지.
- 모서리 둥글기 0. 글로우·그라데이션·기울인 숫자 금지.
- 단계 표시: 운동 = `--c-accent` 전면 + `--c-on-accent` 글씨, 휴식 = `--c-bg` + `--c-fg`, 준비 = `--c-surface-2` + 숫자 `--c-accent`. 라운드 간 휴식은 휴식과 같은 색, 이름 "라운드 휴식"/`ROUND REST`.
- 시간 표시: 60초 미만 `20`, 60초 이상 `3:00`. 총 시간은 항상 `m:ss`.
- 소리는 Web Audio API 하나로만 낸다. `<audio>`, Web Speech API 금지. 모든 소리는 `AudioContext.currentTime` 기준으로 미리 예약한다.
- 신호음: 3·2·1초 전 880Hz 0.12초, 전환 1320Hz 0.45초, 전체 끝 1320Hz 0.9초. 파형 square, 최대 게인 0.22.
- 카운트 k(3·2·1)는 단계 길이가 k보다 길 때만 낸다(`k < duration`). 단계 시작 순간의 전환음과 겹치지 않게 하기 위해서다.
- 한국어 음성 모드라도 길이 3초 이하 단계의 카운트는 신호음으로 낸다("삼, 이, 일"이 다 들어가는 4초 이상 단계만 음성). 전환음·끝 음은 음성 그대로.
- 숫자·영문 라벨 글꼴은 Barlow Condensed(OFL, `@fontsource/barlow-condensed`), 한글은 Pretendard. CSS 변수 `--font-num`, `--font-kr`. Satoshi는 쓰지 않는다.
- 편집 범위: 준비·휴식·라운드 간 휴식 0~3600초, 운동 5~3600초, 세트·라운드 1~99. 시간 스텝: 60초 미만 5초, 60초 이상 15초.
- 이름 최대 20자. 비우면 `${format(work)}/${format(rest)} 인터벌`.
- 하단 메뉴는 `list`, `settings` 화면에만 표시한다.
- 브라우저 `alert`/`confirm`/`prompt` 금지. 삭제는 두 번 눌러 확정.
- 화면 문구는 한국어, 영문 라벨은 대문자 + 자간 `--tr-widest`.

## Review Focus

1. **운동 중 화면 잠금·앱 전환 후 복귀**: 돌아오면 남은 시간이 맞고, 지난 소리는 울리지 않고 남은 소리만 다시 예약되며, Wake Lock을 다시 잡는다. → Task 8 `resyncs after visibility change`
2. **일시정지 화면 버튼을 누를 때 탭이 두 번 처리됨**: "다음 단계로"를 누르면 건너뛰고 재개만 되어야 하며, 화면 탭 처리로 다시 일시정지되면 안 된다. → Task 8 `button tap does not also toggle pause`
3. **깨지거나 다른 앱의 백업 파일**: JSON 아님, `app`이 다름, 필드 누락, 음수·범위 밖 값 → 거부하고 기존 데이터는 그대로. → Task 5 `rejects ...` 테스트들
4. **극단적인 타이머 값**: 준비 0, 휴식 0, 1세트 1라운드, 라운드 1인데 라운드 휴식 있음, 운동 3600초 → 순서·표시가 깨지지 않는다. → Task 1 `edge configs`
5. **끝난 뒤·마지막 단계에서 조작**: 마지막 단계에서 건너뛰기, 일시정지 중 처음부터, 끝난 상태에서 종료 → 예외 없이 동작. → Task 2 `controls at boundaries`
