# 운동 인터벌 타이머 — 서비스 기획 초안

> 상태: 초안 (2026-11-04). 확정본은 `docs/superpowers/specs/2026-11-04-ttaeng-design.md`. 내용이 다르면 확정본을 따른다.

## 1. 배경

App Store의 "타이머 플러스 - 운동 타이머"(ArGames)와 같은 종류의 인터벌 타이머를 직접 만든다. 기능 구성은 참고하되 이름, 아이콘, 화면 디자인은 새로 만든다.

### 참고 앱 분석 요약

| 항목 | 내용 |
|---|---|
| 핵심 기능 | 준비/운동/휴식 시간 + 라운드·사이클 조합 인터벌 타이머 (HIIT, 타바타, 서킷) |
| 부가 기능 | 무제한 타이머 저장, 음성 안내, 메트로놈 틱 소리, 화면 플래시, 백그라운드 동작, 운동 기록, Apple Watch·HealthKit 연동 |
| 수익 구조 | 무료 + 월 구독 4,400원, 평생 이용권 17,000~33,000원, 광고 추적 데이터 수집 |
| 평가 | 4.8점 (3.6만 개). 큰 글씨, 음성·메트로놈, 직관적 설정이 호평 |
| 불만 | 무료로는 1회 사용 후 제한, 월 자동결제 부담 |

불만이 유료화와 사용 제한에 집중되어 있다. 광고 없는 완전 무료, 데이터는 기기에만 저장하는 구조가 이 앱과의 차이가 된다.

## 2. 확정된 사항

- **비용**: 무료 배포. 서버, DB 없음.
- **배포**: GitHub 레포 `yes-eul-jeong/timer-for-hwang`에서 작업하고 GitHub Pages로 호스팅.
- **설치 방식**: 홈 화면에 추가하는 웹앱(PWA). 앱스토어를 거치지 않는다.
- **데이터**: 모두 기기 로컬에 저장.
- **화면**: 모바일 최적화.
- **대상 기기**: iPhone 중심, Android에서도 사용 가능해야 함.
- **사용 규모**: 5~10명, 주로 저녁 시간대. 트래픽은 적다.
- **백업**: 설정 화면에 JSON 백업 내보내기/불러오기 기능을 넣는다.

## 3. 기술 방향 (제안, 반대 의견 없음)

- **형태**: PWA (Service Worker로 오프라인 실행, Web App Manifest로 홈 화면 설치)
- **저장소**: IndexedDB (타이머 설정, 운동 기록), 간단한 설정값은 localStorage
- **데이터 보존 요청**: `navigator.storage.persist()` 호출
- **화면 꺼짐 방지**: Screen Wake Lock API
- **스택 후보**: Vite + TypeScript + React 또는 Svelte (미정)
- **실행 환경**: 로컬에 Node가 없으므로 빌드와 개발 서버는 Docker 컨테이너에서 실행

## 4. 플랫폼 제약

| 항목 | iPhone (Safari·크롬 모두 WebKit) | Android 크롬 |
|---|---|---|
| 설치 | 공유 메뉴 → 홈 화면에 추가 (수동 안내 필요) | 설치 안내 배너 표시 |
| 백그라운드 | 화면을 끄거나 앱을 전환하면 타이머·소리 멈춤 또는 지연 | 동일하게 제한됨 |
| 데이터 보존 | 홈 화면 설치 시 7일 자동 삭제 정책 미적용. 앱 삭제·저장 공간 부족 시 삭제 가능 | 설치 후 persist 허용 시 유지 |
| 불가능한 기능 | Apple Watch, HealthKit | — |

대응:
- 운동 중에는 Wake Lock으로 화면을 켜두는 것을 기본 동작으로 한다.
- 화면이 꺼졌다 돌아오면 시작 시각 기준으로 경과 시간을 다시 계산해서 타이머 표시가 어긋나지 않게 한다.
- 백그라운드 동작이 꼭 필요해지면 Capacitor로 감싼 Android APK를 GitHub Releases로 배포하는 방안을 검토한다. iOS 네이티브 배포는 유료 개발자 계정(연 $99)이 필요하다.

## 5. 백업 기능 동작

**내보내기**: 설정 → "백업 내보내기" → 타이머와 운동 기록을 `timer-backup-YYYY-MM-DD.json` 파일로 생성 → iPhone은 공유 시트(파일 앱, iCloud Drive, 메신저 등), Android는 다운로드 또는 공유 시트.

**불러오기**: 설정 → "백업 불러오기" → 파일 선택 → 형식·버전 검사 → 덮어쓰기 또는 합치기 선택.

**파일 형식 (예시)**

```json
{
  "version": 1,
  "exportedAt": "2026-11-04T09:00:00Z",
  "timers": [
    { "id": "t1", "name": "타바타", "prepare": 10, "work": 20, "rest": 10, "rounds": 8, "cycles": 1 }
  ],
  "history": [
    { "timerId": "t1", "startedAt": "2026-11-03T07:30:00Z", "completed": true }
  ]
}
```

자동 동기화는 하지 않는다. 마지막 백업 후 일정 기간이 지나면 백업을 권하는 알림을 띄우는 방안을 검토한다.

## 6. 아직 정하지 않은 것

- 사용자들이 이 앱을 쓰는 실제 상황 (어떤 운동, 어디서, 휴대폰을 어디에 두는지)
- 첫 버전에 넣을 기능 범위 (운동 기록, 음성 안내, 메트로놈, 화면 플래시, 프리셋 등)
- 음성 안내 방식 (브라우저 음성 합성 vs 녹음 파일), 언어
- 화면 구성과 디자인 방향
- 프레임워크 (React / Svelte)
- 앱 이름
